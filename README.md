# 划时代双人对战游戏 (Epoch-Making Dice Battle)

这是一个基于 Python 和 Pygame 开发的回合制策略骰子对战游戏。玩家可以选择不同的角色和技能，在随机变化的场地中进行 1v1 对决。游戏支持本地双人对战 (PvP) 和人机对战 (PvE)。

## 🎮 游戏特色

### 1. 多样化的角色 (Characters)
每个角色都有独特的属性（生命值、攻击骰子数、防御骰子数）和被动技能：
*   **救世主 (Savior):** 低血量吸血，高血量反伤。
*   **死灵法师 (Necromancer):** 首次死亡时有机会半血复活。
*   **剑鱼骑士 (Swordfish):** 攻击骰子全为偶数时伤害暴增。
*   **银鬃铁卫 (Silvermane):** 受到特定范围伤害时触发真实伤害反击。
*   **丰饶神鹿 (Deer):** 攻击附加“树种”，延迟造成爆发伤害。
*   **碎星王虫 (Star Bug):** 骰子点数成对出现时大幅削弱对方防御。

### 2. 策略性技能骰子 (Skill Dice)
除了普通攻防骰子，玩家还携带一个特殊技能骰子：
*   **魔术骰子:** 投掷后可将任意一个骰子修改为指定点数。
*   **卫星骰子:** 召唤卫星强制更改当前场地天气。
*   **治疗骰子:** 投出的点数直接转化为生命回复。
*   **星盾骰子:** 防守专用，投出 1 点可免疫本回合致死伤害。

### 3. 动态场地系统 (Field Effects)
每一局或通过技能会改变场地，影响战局：
*   **平安夜 (Normal):** 无特殊效果。
*   **沙尘暴 (Sandstorm):** 每回合双方扣血。
*   **雷暴雨 (Storm):** 强制重投最大的骰子。
*   **海市蜃楼 (Mirror):** 攻防数值互换。
*   **低重力/顺风 (Low Gravity):** 所有骰子点数 +1。
*   **暴雪 (Blizzard):** 所有骰子点数 -1。
*   **大雾 (Fog):** 防守方获得额外防御骰子。
*   **冰雹 (Hail):** 无法投出 6 点。
*   **酸雨 (Acid Rain):** 防守点数减半。

### 4. 游戏模式
*   **玩家对战 (PvP):** 本地双人轮流操作。
*   **人机对战 (PvE):** 挑战具备一定策略的 AI 对手。

## 🛠️ 安装与运行

### 环境要求
*   Python 3.x
*   Pygame

### 安装依赖
```bash
pip install pygame
```

### 运行游戏
**图形界面版 (推荐):**
```bash
python gui_main.py
```

**命令行版 (纯文本体验):**
```bash
python main.py
```

## 📂 项目结构

*   `gui_main.py`: **游戏主入口 (GUI)**，包含界面绘制和交互逻辑。
*   `main.py`: 命令行版本入口。
*   `game_engine.py`: 核心游戏引擎，处理回合流程、伤害计算和规则判定。
*   `character.py`: 角色类定义及属性。
*   `skill.py`: 技能类定义。
*   `field.py`: 场地效果定义。
*   `dice.py`: 骰子基础类。
*   `player.py`: 玩家类定义。
*   `ui_elements.py` / `ui_components.py`: GUI 界面组件。
*   `constants.py`: 游戏常量配置。

## 🕹️ 玩法简介

1.  **选择模式:** 在主界面选择 PvP 或 PvE。
2.  **选择角色:** 双方轮流选择出战角色。
3.  **选择技能:** 为角色搭配一个技能骰子。
4.  **抛硬币:** 决定先手方。
5.  **战斗流程:**
    *   **回合开始:** 结算场地效果和持续性状态（如树种）。
    *   **进攻阶段:** 进攻方投掷骰子 -> 选择是否使用技能 -> 选择是否重投 -> 确定最终攻击点数。
    *   **防守阶段:** 防守方投掷骰子 -> (若有星盾) 使用技能 -> 确定最终防御点数。
    *   **结算:** 计算伤害 = 攻击总点数 - 防御总点数 (受场地和被动修正)。
6.  **胜利条件:** 击败对手，使其生命值归零。
